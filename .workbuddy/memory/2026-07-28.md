# 2026-07-28

## DefaultEmoji 全链路性能优化

### 修改文件
- `data/DefaultEmoji.kt` — 解析器提速 + 全局 Bitmap 缓存 + 预热 API
- `ui/chat/components/DefaultEmojiTextField.kt` — 增量 Span 更新 + 预缩放解码 + 快速路径
- `ui/chat/components/MessageBubble.kt` — derivedStateOf + 预加载 Bitmap 替代 Coil
- `ui/chat/components/EmojiPanel.kt` — DefaultEmojiItem 使用直接 Bitmap 替代 Coil

### 核心改动

1. **DefaultEmoji.kt**:
   - `DefaultEmojiCatalog.emojisByName` 预构建全局 name→Emoji Map，避免每次 `findMatches()` 创建 `associateBy`
   - 新增 `DefaultEmojiBitmapCache` 全局 LRU 缓存（16MB），供所有层共用
   - `load()` 使用 `BitmapFactory.Options.inSampleSize` 预缩放解码，替代"全量解码 + scale + recycle"的双份内存峰值
   - 新增 `prewarmBitmapCache()` API，可在启动/进聊天前后台预热

2. **DefaultEmojiTextField.kt**:
   - `applyEmojiSpansIncremental()` 增量更新：仅 diff old/new 文本的 `commonPrefixWith`，移除差异区之后的旧 Span 并只重建差异段
   - `onSelectionChanged()` 快速路径：检测文本是否含 `[.` 标记，无标记时跳过正则解析
   - `DefaultEmojiSpan` 内缓存 bitmap 尺寸，避免 layout 时重复 getter 调用
   - 移除私有 `DefaultEmojiBitmapCache`，使用全局共享缓存

3. **MessageBubble.kt**:
   - `emojiMatches` 改用 `derivedStateOf`，避免 `defaultEmojis` List 引用变化触发重组
   - 预加载表情 Bitmap 到 `emojiBitmaps` state map，InlineTextContent 内优先使用直接 Bitmap 渲染（跳过 Coil）
   - `inlineContent` 加 `remember` key 防止非必要重建

4. **EmojiPanel.kt**:
   - `DefaultEmojiItem` 从 `AsyncImage(Coil)` 改为优先读取 `DefaultEmojiBitmapCache`，命中时直接用 `Image(bitmap)` 渲染
   - 首次未命中时 `LaunchedEffect` 异步加载 + fallback 到 Coil

### 启动预热建议
在 Application.onCreate() 或 ChatScreen 首次进入时调用：
```kotlin
DefaultEmojiCatalog.prewarmBitmapCache(
    assetManager = context.assets,
    targetHeights = intArrayOf(24, 32, 48), // 不同场景的表情高度
    scope = applicationScope
)
```
